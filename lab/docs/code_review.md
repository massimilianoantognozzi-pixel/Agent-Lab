# Review dell'agente freelance

Il parent possiede le scritture. Reviewer separati leggono scope, consumer e
prove; nessun worker esecutivo accede agli originali. Fix e nuovo riscontro
precedono la chiusura. Il codice generato dal modello viene verificato con
test e criteri congelati, non con la sola spiegazione del modello.

Controlli specifici: path normalizzato prima di I/O; nessuna espansione home;
symlink/reparse; file riservati; hash prima/dopo; backup fuori dal job;
manifest/container e cleanup con identita propria; assenza credenziali;
codice di progetto eseguito solo nel contesto previsto; correttezza dei PASS;
KB con prove e ambito, senza contaminare requisiti/decisioni approvate.
